Guide / Layout

Layout primitives

Every screen in tessera is built from two containers: a stack that lays children along one axis, and a grid that places them in equal tracks. Both take a gap, never margins, so spacing lives in one place.

import { Stack, Grid } from "tessera"

const card  = Stack({ axis: "y", gap: 12 })
const board = Grid({ columns: 3, gap: 24 })

board.add(card, card, card)

A grid never guesses. Column widths are equal fractions of the space left after gaps, so a three-column grid at any width has three identical tracks and two identical gaps.

Nesting

Stacks nest inside grid cells and grids nest inside stacks. Depth costs nothing at layout time; each container measures once.

const page = Stack({ axis: "y", gap: 32 })
page.add(header, Grid({ columns: 12, gap: 24 }), footer)

Try it live in the playground. It runs on the dev server at localhost:5173.

Why no margins

Margins belong to the child and collapse in ways that depend on the parent. A gap belongs to the parent and means one thing. Moving every spacing decision to the container makes a layout readable from one line of code.

Alignment

Stacks align children on the cross axis with align and distribute leftover space on the main axis with justify. Grids align each cell in its track. Neither ever stretches a child past its content unless asked.

Performance

Layout is a single pass from the root. A container asks each child for its size once, then places it. There is no second measure, so a thousand cards lay out in the time a hundred take multiplied by ten.
