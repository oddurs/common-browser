# Security policy

## Supported versions

Common Browser has not had a release yet. Until 1.0, only the latest release (and `main`)
receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/oddurs/common-browser/security/advisories/new).
Please do not open a public issue.

Include what you found, how to reproduce it, and which version or commit you tested.

## What to expect

- An acknowledgement within 3 working days.
- An assessment and, where the report is valid, a plan for a fix within 14 days.
- Credit in the release notes when the fix ships, unless you ask to stay anonymous.
