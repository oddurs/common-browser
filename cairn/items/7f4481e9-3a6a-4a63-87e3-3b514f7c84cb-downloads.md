## Problem

Clicking a download link must do something visible and predictable.

## Proposal

Use `WKDownload`. Save to `downloads.dir` (default `~/Downloads`) and never overwrite: add " 2",
" 3" and so on before the extension. A toast shows progress and, when done, the file name. `⌥⌘L`
reveals the most recent download in Finder.

## Acceptance criteria

- [ ] Downloading the same file twice produces `name.ext` and `name 2.ext`, covered by a test of the naming function.
- [ ] A failed or cancelled download leaves no partial file and says why.
- [ ] Downloads are quarantined like Safari's, so Gatekeeper checks them.
