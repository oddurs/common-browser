## Problem

Printing, and saving as a PDF, is expected of any browser.

## Proposal

`⌘P` runs the web view's print operation with the system print panel.

## Acceptance criteria

- [ ] The print panel shows a preview of the page, and Save as PDF produces a PDF of it.
