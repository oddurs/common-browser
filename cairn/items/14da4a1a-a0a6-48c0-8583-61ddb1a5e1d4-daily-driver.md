## Ships

Fast, private and accessible enough to be your only browser: content blocking, permission prompts,
VoiceOver support, and memory that stays flat with fifty pages open. A Linux spike proves the core
can host a second shell before v1.0 freezes its API.

## Done when

- [ ] The performance budgets in `docs/performance.md` are met and measured by `scripts/bench`.
- [ ] Every control in the browser's own UI can be reached and operated with VoiceOver.
- [ ] The Linux spike's answer is written, and the core API changes it asks for are filed.

## Explicitly not in this milestone

- Shipping the Linux shell. The spike proves it can be done; the shell itself comes after v1.0.
