## Ships

A macOS browser you can rely on, and a config file, CLI and core API it will not break without a
major version. No new features: stability, completeness, documentation and trust.

## Done when

- [ ] `common.toml` is versioned, and a v1 file keeps working in every 1.x release.
- [ ] The core API is documented for shell authors, and the Linux spike's changes have landed.
- [ ] A release candidate has been the maintainer's only browser for two weeks with no open p0 bugs.
- [ ] Releases are signed, notarized and installable with one command.

## Explicitly not in this milestone

- Linux and Windows shells. The core is portable and tested on both, and the shells follow v1.0.
- Browser extensions, sync between machines, and password manager integration.
- A settings window. This is by design, not a deferral: the file is the settings.
