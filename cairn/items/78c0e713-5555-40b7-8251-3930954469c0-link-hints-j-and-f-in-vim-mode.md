## Problem

Following a link without the mouse is the keyboard browser's core move.

## Proposal

`⌘J` (or `f` in vim mode) labels every visible link and control with prefix-free letter hints drawn
in the margin style from the prototype. Typing a hint activates it. `⇧⌘J` (or `F`) opens the link as
a new page.

## Acceptance criteria

- [ ] Hints are prefix-free, so no hint is the start of another (tested).
- [ ] Hints cover links inside same-origin iframes.
- [ ] Esc cancels and leaves the page untouched.
