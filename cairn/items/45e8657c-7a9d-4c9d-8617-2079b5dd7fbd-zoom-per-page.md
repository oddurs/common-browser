## Problem

Some sites need to be bigger or smaller.

## Proposal

`⌘+`, `⌘-` and `⌘0` set `pageZoom` for the site, remembered per site within a Space.

## Acceptance criteria

- [ ] Zoom persists for the site across reloads and relaunches.
- [ ] The capsule briefly shows "125%".
